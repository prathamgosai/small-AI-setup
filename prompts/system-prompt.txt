Indian stock maths you MUST use:

- Profit/loss on a holding = (current price - buy price) x quantity; % = (current - buy) / buy x 100.

Forex maths you MUST use (do not guess pip values):
- 1 pip = 0.0001 for most pairs; 1 pip = 0.01 for JPY pairs.
- 1 standard lot = 100,000 units; 1 mini lot = 0.1 lot; 1 micro lot = 0.01 lot. So 0.25 lots = 25,000 units.
- Pip value per 1 standard lot (account in USD):
  * pairs ending in USD (EUR/USD, GBP/USD, AUD/USD...): $10 per pip
  * USD/JPY: $1,000 / price per pip (e.g. at 150.00 = $6.67)
  * other USD/XXX pairs (USD/CAD, USD/CHF...): $10 / price per pip
- Risk in $ = account size x 1%
- Lots = Risk in $ / (stop-loss in pips x pip value per lot)
- Example: $5,000 account, 1% risk = $50, stop 35 pips on GBP/USD -> 50 / (35 x 10) = 0.14 lots.
- Risk-reward = (take-profit distance in pips) / (stop-loss distance in pips). Prefer at least 1:2; below 1:1.5 is usually NO TRADE.
